# ⚽️ Calendrier des Matchs - Club Africain 🔴⚪️

Ajoutez automatiquement tous les prochains matchs du **Club Africain** directement dans votre téléphone ou votre ordinateur ! 

Ce calendrier se met à jour tout seul : si un match est programmé ou repoussé, votre agenda sera mis à jour sans que vous n'ayez rien à faire.

## 🔗 Le lien à copier

Copiez simplement ce lien magique :
👉 **`https://calendrier-ca-api.onrender.com/club-africain.ics`**

## 📱 Comment l'ajouter à votre téléphone/ordinateur ?

**Sur Google Agenda (Android / PC) :**
1. Ouvrez Google Agenda sur un ordinateur.
2. À gauche, à côté de "Autres agendas", cliquez sur le **`+`**.
3. Choisissez **À partir de l'URL**.
4. Collez le lien ci-dessus et cliquez sur **Ajouter l'agenda**.
*(Il apparaîtra ensuite tout seul sur votre téléphone Android).*

**Sur iPhone / iPad (Apple Calendar) :**
1. Allez dans les **Réglages** de votre iPhone.
2. Descendez et appuyez sur **Calendrier** > **Comptes** > **Ajouter un compte**.
3. Choisissez **Autre** > **Ajouter un calendrier avec abonnement**.
4. Collez le lien et appuyez sur **Suivant** puis **Enregistrer**.

**Sur Outlook :**
1. Ouvrez le calendrier Outlook.
2. Cliquez sur **Ajouter un calendrier** > **S'abonner à partir du web**.
3. Collez le lien, donnez-lui un nom (ex: *Club Africain*) et cliquez sur **Importer**.

---
**⚠️ Petite note :** La toute première fois que vous ajoutez ce lien, les matchs peuvent mettre environ 1 minute à apparaître. C'est normal ! Laissez-lui un peu de temps pour chercher les données, ensuite tout sera 100% automatique.
